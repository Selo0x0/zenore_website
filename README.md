# Zenore Website

Single-seller Turkish e-commerce platform for Zenore leather products.

## Stack

- Frontend: Next.js + TypeScript
- Backend: NestJS + TypeScript
- Database: PostgreSQL + Prisma
- Firebase: Auth, Analytics/App Check
- Product images: PostgreSQL metadata + local `/uploads` files for MVP
- Payment: iyzico or PayTR

## Repository Structure

```text
apps/web         Frontend application
apps/api         Backend API
packages/db      Prisma database package
packages/shared  Shared TypeScript types
docs             Architecture and product documentation
```
